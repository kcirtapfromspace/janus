# Janus 0.1.0-preview.19

- **Find Janus in Command-Tab.** Janus now appears in the macOS app switcher and Dock with its app icon. Launching it opens your interview notebook; choosing Janus after closing all its windows reopens the notebook. The menu-bar recording controls remain available when you close the notebook.
- **About in the app menu.** The Janus app menu opens the same About panel, with the full release version, build number and source repository link.
- **Reliable startup upgrades.** Simultaneous startup requests now wait for one library upgrade to finish, preventing a duplicate-column error when opening an older library.

Existing interviews, settings, sign-ins, and automatic updates carry forward. Requires macOS 14.4 or later on Apple silicon.
