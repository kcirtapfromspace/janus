# Janus logo exploration

Identity directions generated with the built-in image generation tool for visual comparison.
**Roman Rhythm B** was selected and redrawn as editable Bezier geometry in
`scripts/make-brand-assets.swift`. The active production assets are in `../../`.

- **01 Threshold:** an architectural passage, transition and agency.
- **02 Counterform:** paired J letterforms, two perspectives in one monogram.
- **03 Reply:** opposing quotation strokes, the feedback missing from the process.
- **04 Parallax:** offset planes, a change in perspective.
- **05 Letterform:** a custom J and an editorial wordmark.
- **06 Hinge:** a circular emblem with two opposing gestures.

`exploration-01.png` is the initial comparison sheet. `prompt.txt` records the generation prompt.
`original-profiles.png` preserves the first Janus identity. Generated concept rasters remain
references; the installed logo, report stamp, and native mark use the shared vector redraw.

The user selected **03 Reply** and requested laughing expressions. `reply-laughing-rejected.png`
records the rejected emoji-like face treatment. `reply-refinements.png` explores laughter through
carved grins, open counters, and a lively typographic rhythm. Their generation prompts are saved
as `reply-laughing-prompt.txt` and `reply-refinements-prompt.txt`.

`roman-rhythm.png` combines the selected Rhythm quotation shapes with the original Roman
profile contours along their outer edges. Both profiles stay upright and face outward;
the quote terminals, separation, and vertical stagger remain. It was generated with the
built-in image tool; its prompt is `roman-rhythm-prompt.txt`.

Two further proportional refinements give the Roman profiles more presence within the quotes:
`roman-rhythm-fuller.png` (A, fuller contour) and `roman-rhythm-taller.png` (B, taller profile).
Both use the approved Roman Rhythm board as their reference, retain the typography and palette,
and were generated with the built-in image tool. Each has a corresponding `-prompt.txt` file.
**B** was selected for the app, menu bar, icon, and reports.
