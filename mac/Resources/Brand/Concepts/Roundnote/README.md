# Roundnote — rejected identity proposal

Recommended product name: **Roundnote**. Pronounced “round-note”. It joins interview rounds
with the personal notebook that holds conversations, reviews, evidence, and preparation.
Use **Roundnote** in prose and **roundnote** in the wordmark. Product descriptor: “Your interview notebook.”

The logo is an R with a speech bubble cut out of its counter. A substantial serif form keeps
it readable as an app icon and connects it to the editorial interface. The counter is transparent,
not a colored shape, so the mark works in a single ink. Color follows the existing forest green,
paper, charcoal, and pale sage palette.

## Assets

- `concept.png`: original identity sheet generated with the built-in imagegen tool.
- `mark.svg`: editable vector interpretation of the proposed conversation monogram.
- `wordmark.svg`: transparent light-mode lockup, with outlined Georgia Bold lettering.
- `wordmark-dark.svg`: transparent dark-mode lockup, with the same geometry.
- `app-icon.png`: native 1024-pixel icon preview made from the vector interpretation.
- `prompt.txt`: the full image-generation prompt.
- `make-assets.swift`: reproducible vector and native PNG generator. Run with `swift`.

The SVG interpretation is separately drawn and does not claim to be a pixel-identical tracing
of the generated image. This proposal was rejected. Janus is the selected product identity;
its active assets live two directories above this exploration.

## Naming screen — 4 October 2026

An initial public web search found Roundnote used for fonts and a music school. No direct
interview-coaching product appeared in that search. This does not establish trademark or domain
availability. Replybook is an alternative emphasizing answers and reflection; an initial exact-name
search found no obvious matching product.
